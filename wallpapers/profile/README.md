# Souprland profile wallpapers

Each `st-*.jpg` file in this directory is a curated `1920x1080` wallpaper
sourced from [Wallhaven](https://wallhaven.cc) and matched to its profile's
color palette and theme.

Source pages, Wallhaven IDs, and direct URLs are recorded in
[`sources.json`](sources.json).

Earlier bundled wallpapers' size/SHA-256 hashes are preserved in
[`legacy-wallpapers.txt`](legacy-wallpapers.txt) so existing installs still
recognize and safely replace previously applied bundled wallpapers.
