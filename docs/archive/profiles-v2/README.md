# Archive: profile set v2 (23 profiles)

On 2026-09-23 the profile system started being rewritten to copy, as closely
as possible, the setups from 15 Reddit posts provided by the user. The profiles
in this directory are the ones used under `presets/profile/` up to that date;
most were nothing more than a theme + a generic bar preset ("like a color
palette").

To restore one, just copy the file under `presets/profile/`. The bar/terminal/
launcher presets and wallpapers they depend on are still in place.
